# Novel Studio

Novel Studio is planned but not implemented in Stage 0.

Stage 0 only prepares:

- feature flag
- capability placeholders
- documentation roadmap
- baseline tests
- reserved module directories

The active roadmap is maintained in:

- `../../docs/NOVEL_STUDIO_ROADMAP.md`
- `../../docs/NOVEL_STAGE0_BASELINE.md`

Do not add Novel Studio business APIs, repositories, services, database tables,
or Flutter business calls before Stage 1.
