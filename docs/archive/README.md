# 文档归档说明

本次整理采用“保留路径、中文精简、集中索引”的归档方式。

## 为什么不移动文件

部分测试、README 和客户端说明引用固定文档路径。为了避免断链，阶段文档仍保留在 `docs/` 根目录，但内容已经改为中文归档版。

## 删除的冗余

- 删除重复的阶段目标长列表。
- 删除重复的“不做内容”段落，只保留边界摘要。
- 删除英文说明中的重复安装和验证描述。
- 保留 API 路径、字段名、命令、配置 key 等技术标识原文。

## 阅读顺序

1. 先读 [../README.md](../README.md)。
2. 再读 [../NOVEL_STUDIO_ROADMAP.md](../NOVEL_STUDIO_ROADMAP.md)。
3. 需要阶段细节时打开对应 `NOVEL_STAGE*.md`。
4. 发布前读 Windows 与 Release 文档。
